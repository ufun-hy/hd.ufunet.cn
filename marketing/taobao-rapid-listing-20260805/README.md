# 淘宝第一轮快速上新素材

本目录用于“扫码抽奖、导入名单抽奖、大屏互动游戏”三个商品方向的第一轮千牛草稿。

- `deliverables/`：6 张 1440×1440 JPG 上传成品及对应 PNG 无损版本，每个商品 2 个视觉方向。
- `exports/svg/`：确定性排版源文件。
- `src/`：内容与生成逻辑。
- `manifest.json`：标题、关键词、图片与来源记录。

画面以项目内真实功能预览和经代码核验的功能信息为主体。中文标题、流程和标签均由 SVG 确定性排版；没有用生成模型绘制文字、二维码或产品界面。

## 重新生成

```bash
node src/generate-assets.mjs
```

生成 SVG 后，用 macOS CoreSVG 转为 1440×1440 JPG。千牛上传时只使用 `deliverables/` 中的文件。
