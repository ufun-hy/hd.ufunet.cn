# 导入抽奖结果组件验证

当前视觉实现以用户提供的 `中奖界面布局演示（动效版） (2).html` 为准，原文件完整保存为 `reference.html`，仅用于本地对照，不部署到服务器。中奖记录参考 `中奖记录（金色·多字段）.html`，完整保存为 `records-reference.html`。

## 预览

在仓库根目录运行 `python3 -m http.server 8767 --bind 127.0.0.1`。
打开 `http://127.0.0.1:8767/tests/importcj-result/`，支持 `?fields=1` 至 `?fields=4`、`?fields=4&records=1`、`?count=3`、`?count=20`、`?count=40`、`?count=60`、`?count=31&kind=groups`、`?count=3&kind=long`、`?kind=message`、`?zoom=1.5`。
预览只使用本地模拟名单，不加载抽奖控制器，不调用业务接口。

## 参考规则

- `best` 遍历列数，按 `min(行高 ÷ HF, 列宽 ÷ WF, 屏高 × .24)`，其中 1–4 字段的 HF 为 `[1.9, 2.4, 3.2, 3.2]`、WF 为 `[2.6, 2.8, 3.8, 3.8]` 选择最大字号，保留参考文件的 `.5` 比较阈值。
- 初次使用全部人数计算；字号低于屏高的 7% 才分页，再从 `min(15, 人数)` 向下选容量。不保留旧版固定列数、12 人上限或文本宽度测量逻辑。
- 主字号为计算值，第二字段字号为主字号的 0.5 倍；第三、第四字段进入底部分隔区，标签为 `max(11, 主字号 × .2)`，值为 `max(13, 主字号 × .3)`。1、2 字段不创建底部区域，按对应 HF/WF 计算尺寸；3 字段底部一列，4 字段底部两列。卡片、颜色、字体、间距、阴影、边框和圆角均使用参考文件公式及样式。
- 整轮采用同一布局，多个奖项按组连续分页；每页复用同一尺寸，末页不足时居中。
- 首张卡在结果渲染时立即揭晓，删除参考中数字滚动使用的 1200ms 起步等待；后续逐个间隔 `min(380, 2200 / 当前页人数)`。放大 .55 秒，高光延迟 .15 秒持续 1 秒，前 12 张卡产生彩纸。
- 首次轮播启动等待 `当前页人数 × 间隔 + 2500ms`，随后每 4 秒翻页；后续页只播放放大，不重复高光和彩纸。页脚仅显示“第 x / y 页”，不保留旧版上一页/下一页/暂停按钮及旧停留时间配置。
- 不再按文本长度缩字号或增加滚动条。与参考文件相同，长字段保持固定字号、不换行，主字段超出卡片范围的部分会被裁切，次字段及底部字段单行省略，并以 title 展示完整的已遮罩值；没有修改原始字段值。

## 按用户要求保留的差异与应用接入

不加入数字随机跳动：首张卡立即开始揭晓，其余卡片在轮到之前不可见、字段为空；轮到时才填入接口已确认、已做隐私格式化的值，并同时播放放大、高光和彩纸。
背景和控制台沿用现有页面；不加入示例背景、奖品等级、奖品下方人数行或重新揭晓按钮。
实际奖品图片替代示例占位框，仍只在 3 人以内且横屏时显示。
示例下方工具栏的占用高度替换为现有控制台占用高度，结果区域按真实屏幕比例等比放入剩余空间。
保留主字段/其他字段配置、空值回退、文本安全及多奖项数据适配；后台抽奖、去重、留言和头像组件不变。
关闭、查看记录或切到后台时清理动画与轮播，回到结果页静态显示当前页；同页缩放只更新尺寸，保留原卡片和揭晓定时器，不重建节点或重播动效。减少动态效果偏好关闭视觉动画。
启用新结果组件时，停止旧中奖烟花视频，不渲染旧中奖列表，也不启动隐藏列表的自动滚动。

## 记录接入

结果与记录共用 `resultmainfield` / `resultextra1/2/3`，从 `fieldconfig` 取得实际可配置字段及名称。只统计启用并去重后的显示字段，不为未配置的第 3、4 字段预留高度；个别已启用字段值缺失显示 `—`，主值仍保留已有回退。
记录使用原接口和真实奖项分组；横屏两列、竖屏一列，卡片高度由实际字段内容决定。保留加载、失败重试、空态及关闭入口，增加参考中的滚动回顶。所有记录样式只作用于 ImportCJ 抽屉，通用头像和留言组件不变。

## 验证

在已建立的 Ego task space 中执行，数字替换成当前空间 ID：

```sh
{ printf 'globalThis.RESULT_TEST_SPACE=18;\n'; cat tests/importcj-result/browser-checks.mjs; } | ego-browser nodejs
{ printf 'globalThis.RESULT_TEST_SPACE=18;\n'; cat tests/importcj-result/motion-checks.mjs; } | ego-browser nodejs
{ printf 'globalThis.RESULT_TEST_SPACE=18;\n'; cat tests/importcj-result/resize-checks.mjs; } | ego-browser nodejs
```

- `browser-checks.mjs` 在 iframe 中执行原 HTML，统一人数、视口和工具栏占用高度；6 种尺寸 × 12 种人数，× 4 种字段数，共 288 组逐项比较画布、分页容量、卡片宽高、字号，并检查完整名单、字段映射及生命周期。
- `records-checks.mjs` 对照记录参考 HTML 检查 48 组横竖屏/字段数/人数下的卡片尺寸、字体和抽屉宽度，并验证两页字段顺序和名称一致、showitems、分组、空值回退、关闭字段、重复字段、加载/空态/错误、前导零和安全文本。
- `motion-checks.mjs` 对 1–4 字段分别检查揭晓前卡片不可见且字段为空、揭晓时填值、彩纸与 4 秒翻页的精确时序，以及缩放保留节点与定时器、返回静态显示、后台清理和减少动态效果。
- `controller-checks.mjs` 使用真实控制器的 `stopLottery` 方法和本地模拟数据，覆盖 1/5/6 三种模式；确认新结果只触发一次，不播放旧视频、不渲染旧列表或启动旧滚动，不调用业务 API。
- `resize-checks.mjs` 检查 912 组连续宽度、跨页尺寸、CSS zoom、控制台避让、透明背景及控制台与共享组件样式一致。

字段配置继续沿用既有 `styleconfig[resultmainfield]` 与 `styleconfig[resultextra1/2/3]`。本地没有 PHP 运行环境且现有控制器加密，字段配置的服务端保存/回读仍需测试环境验证。

## 卡片与字段颜色

后台“中奖结果展示”新增卡片背景模式：默认金色渐变（旧配置未设置时沿用）或自定义纯色；`styleconfig[resultcardmode]` / `styleconfig[resultcardcolor]` 同时作用于结果及记录卡片。
字段内容复用 `fieldconfig[].fieldcolor`，按原字段索引携带颜色，主字段回退及重新排序后仍正确对应；标签颜色保留默认深棕。颜色无效时使用原样式。舞台背景和控制台不受影响。
预览支持 `?fields=4&cardcolor=%23e6f0ff&fieldcolors=%23112233,%23445566,%23778899,%23123456`，添加 `&records=1` 查看记录。
`color-checks.mjs` 验证两页自定义背景、默认渐变、字段重排/空值回退的颜色、无效输入、分页、缩放、返回、即时揭晓和共享组件隔离。
后台新增字段的保存回读仍需在可登录环境验证；本地没有 PHP 运行环境，未修改或调用后台保存接口。
