# 竞品成交时段、支付买家和广告强度监察口径

## 执行时间

- 每天 10:30：确认前一完整自然日的数据。
- 每天 23:30：读取当日实时小时分布，覆盖当天大部分成交时段。
- 每周一：输出最近 7 天汇总和策略变化。

## 成交时段

- 数据位置：生意参谋竞店分析的“实时 → 销售分析 → 支付买家数”。
- 记录内容：00:00–23:00 各小时支付买家具体值或脱敏区间、页面更新时间。
- 输出：每天前 3 个成交小时、连续高峰时段；积累 7 天后区分工作日与周末。
- 限制：尚未结束的小时不能当作零成交；区间数据不得擅自取中位数冒充实际值。

## 每日成交量

- 可用指标：竞店和核心竞品逐日“支付买家数”。
- 展示形式：较低时可能显示具体数字，较高时可能显示 `10–50`、`50–75` 等区间。
- 限制：支付买家数不是订单笔数，一个买家可能产生多笔订单。
- 输出：逐日表、7 日趋势、异常日和区间变化。

## 广告投放金额

- 不可直接取得：竞争对手广告后台的真实消耗、出价、余额和精确点击成本。
- 可直接监察：核心词赞助位出现次数与位置、关键词推广访客区间、广告成交占比提示、Top 商品变化。
- 可选估算：竞品关键词推广访客区间 × 本店相同关键词簇近 7 日平均点击成本。
- 输出要求：必须标注“估算”，同时给出范围、置信度、公式、假设和误差来源；数据不足时只给广告强度，不给金额。
