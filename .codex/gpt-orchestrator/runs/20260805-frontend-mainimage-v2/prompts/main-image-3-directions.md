Product: event large-screen interactive lottery system for Taobao.

Target output: square ecommerce main-image base artwork for Taobao, suitable for later deterministic Chinese text overlay.

Required quality: ultra-sharp, high-resolution, commercial UI advertising visual, at least 2048 x 2048 source quality if the tool supports it.

Use the attached existing Taobao product images only to understand category, information density, and ecommerce main-image structure. Do not copy their low-resolution look, claims, exact text, QR codes, stage crowd scenes, or decorative 3D props.

Use the local product front-end screen references only as function-structure references: avatar pool, winner cards, prize panels, spinning/rolling participant states, racing tracks, ranking bars, red packet rain, and large display UI. Do not reuse the old screenshots as direct image layers.

Global negative constraints:

- no backend dashboard
- no admin console
- no operation flow diagram
- no phone participation screen as the main subject
- no real crowd, no event stage audience, no presenter

- no QR code

The image should feel like a polished, upgraded, buyer-visible front-end big screen of the product. It should look like the software interface itself is the hero. Keep the screen details dense enough that a buyer can understand this is an interactive lottery or interactive game system even before text is added.

Composition rule:

Leave a clean top-left or top band area for later Chinese title overlay. Keep the core front-end screen effect in the middle and lower two-thirds. Use visual hierarchy suitable for Taobao mobile search: readable structure at thumbnail size, rich detail at full size.
