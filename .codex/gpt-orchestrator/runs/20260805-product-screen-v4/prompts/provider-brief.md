# Taobao product-screen main-image assignment

## Role

You are producing a high-fidelity ecommerce product visual for a real big-screen interaction software product. The screen UI itself is the product. This is not a venue scene, hardware mockup, admin dashboard, or operation tutorial.

## Shared constraints

- Output: one clean square 1:1 image, at least 1024 x 1024.
- Camera: straight-on orthographic screen capture. The image is the full-screen UI itself.
- Keep the product screen dominant. It should occupy at least 78% of the square canvas.
- Reserve only a restrained dark-gradient safe area near the top for later local Chinese copy.
- Create a realistic, implementation-plausible event big-screen interface with clear focal hierarchy and polished motion-state cues.
- Preserve the supplied guide's screen structure, but redesign it in high definition rather than tracing low-resolution pixels.
- No physical monitor, television frame, stand, laptop, browser chrome, desktop window, or perspective mockup.
- No admin sidebar, settings form, tabs, data charts, analytics, table, filtering controls, or management console.
- No phone, hand, presenter, crowd, audience, stage, venue, spotlight rig, workflow arrows, or tutorial steps.
- No readable Chinese or English text. Use abstract short bars or masked glyph-like blocks only where labels would exist.
- No logo, trademark, QR code, price, watermark, badge, certification, or unsupported claim.
- Avoid generic sci-fi dashboard styling. It must read as an event-facing lottery/game screen from several meters away.

## Direction A — QR participant lottery

Reference role: use the supplied A guide only for layout and product morphology.

- Visible state: lottery is actively rolling and one participant is becoming the winner.
- Center: one large circular avatar/photo placeholder inside a luminous but restrained winner ring.
- Around it: a dense participant pool of small circular avatars or photo tiles, visibly feeding into the center.
- One compact prize card or gift icon area; a small row of already-selected winners.
- Visual language: premium blue-violet with warm gold highlights; celebratory but still software-like.
- It must communicate participant lottery immediately, without showing an actual QR code or mobile phone.

## Direction B — Imported-name list lottery

Reference role: use the supplied B guide only for layout and product morphology.

- Visible state: imported names are rolling in large central name cards/slot bands, with one selected result highlighted.
- Use name strips and participant chips rather than portrait-heavy UI, so it is clearly distinct from Direction A.
- Include a compact prize area and a short winner lineup at the bottom or side.
- Visual language: red and deep burgundy with refined gold, suitable for annual meetings and formal events.
- The result must be a front-end drawing screen, never a spreadsheet, contact list, or import-management page.

## Direction C — Big-screen interactive race game

Reference role: use the supplied C guide only for layout and product morphology.

- Visible state: six participants are competing in a colorful race with visible progress and ranking.
- Center: broad race field with six lanes and distinct player markers.
- Side or upper area: compact top-three ranking; finish line visible.
- Visual language: deep blue background with saturated cyan, orange, magenta, lime, and violet accents.
- It must read as a real event game screen, not a cinematic racing poster and not a game-management dashboard.

## Delivery

Generate the requested image directly. Do not explain the design unless asked. Do not merge several directions into a collage.
